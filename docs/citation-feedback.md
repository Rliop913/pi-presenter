# Semantic review, not lexical output gates

The previous literal-citation diagnostic mechanism has been removed. It rejected otherwise usable language because model quotations used different line breaks, capitalization or typography, and because translated numeric language did not match original strings. That was a normalization gate, not an assessment of factual truth.

Research and planning now use natural-language model responses preserved as received. They are not required to return JSON, fixed wording or exact source substrings. The independent reviewer receives the approved sources and analyses and evaluates support, accuracy, uncertainty and narrative fidelity semantically.

Machine-readable data is used only where software needs a compiler handoff (slide/reference/chart structures) or a review/control decision. Explanatory prose and Markdown may surround the object. Narrative text has no small sentence-length/typography/numeric constraints. Extra descriptive metadata is ignored rather than treated as executable behavior.

Structural link checks remain for IDs referring to compiler inputs, chart labels/value array lengths, approved slide count, allowed layout fields, immutable unaffected patch scope and actual render manifests. Authority checks remain for native approval, exact model/effort identity, no tools, bounded network/install authority, file integrity, cancellation and time/call budgets. These are not claims that a string is true or false.

Independent factual and actual-image review still decide whether export is appropriate. Removing lexical gates does not certify fabricated evidence or waive semantic review. The prior captured citation failures are historical records, not validated decks.
